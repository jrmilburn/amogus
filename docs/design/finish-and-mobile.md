# Endgame, sound and touch refinement

The incumbent Hollow station language is retained: original engineer art, dark teal instruments, amber actions, mint crew success and coral danger. This is an extension, not a new brand world.

After death, ghost chat is a compact disclosure; during a meeting it moves inside the focus-protected meeting dialog. The final modal puts personal Victory/Defeat, reason and winning engineers before the full role disclosure and host Play again. No living chat receives ghost text.

Sound uses original Web Audio synthesis, not external samples. Source and license follow this repository. Master/music/SFX values are clamped and optionally saved; event sounds never carry semantic information unavailable visually. Footsteps and vent cues use distance/pan and current visibility. Station ambience and audio suspend with hidden tabs.

Polish uses existing additive glow rather than a new full-screen bloom filter, short witness-only kill feedback, twelve bounded task sparks and starfield motion. Reduced motion removes shake, particles and transitions and uses steady alarm lighting.

Touch layouts use a three-column 64px contextual action grid, retaining cooldown/allowance text. Fine-pointer layouts retain original nesting. Controls respond to pointer-mode changes; joystick remains an 8px dead zone with 40px ramp. Portrait advice is dismissible. Wake lock is optional and released on closing the station. Native dialog contents remain scrollable and text fields stay zoom-accessible.

Impeccable detector found no issues on the settled #18–#22 surfaces. Independent review led to desktop nesting, touch timer and in-map reconnect feedback fixes. No enabled browser surface was available, so desktop/mobile screenshots, measured focus/contrast/layout, audio listening and GPU/FPS acceptance are **pending**, not inferred from source review.
