# Engineer source art

`parts.png` is the project-owned source sheet generated with the built-in ImageGen tool on 2026-09-06. It contains nine isolated rig parts on a transparent background. The returned image is 1254 × 1254; the builder uses inspected part bounds rather than assuming the requested canvas size.

`scripts/build-characters.ts` crops and rigs this source into a deterministic padded atlas. Suit parts are converted to neutral grayscale; the visor and backpack preserve their source colours. No image-generation service or network connection is needed for subsequent builds. Keep this source tracked in Git; the generated runtime atlas is ignored and recreated by `pnpm --filter @mutiny/client assets`.
